What I've built so far

Two academic projects that show how I approach a problem: work out the structure first, then build it properly.

MediCare Hospital — Patient Admission System

JAVA
purpose

A console-based system for managing patient admissions in a hospital setting — registering patients, assigning them to wards and beds, and tracking their category of care.

description

Built around core object-oriented principles: an enum for patient categories, a class hierarchy for patients and inpatients, and dedicated classes for beds, wards, and overall hospital administration, with full create/read/update/delete functionality for patient records.

technologies

Java, object-oriented design (inheritance, encapsulation), JUnit for testing

ServiceRequestApp — Service Request Logging System

JAVA · JUNIT
purpose

A Java application for logging and managing service requests, so each request can be tracked from creation through to updates.

description

Users can add a new service request, view existing requests, and update a request's description. Each request is automatically assigned a unique request code on creation, so records stay distinguishable and traceable.

technologies

Java, JUnit for unit testing

QuickChat — Console-Based Java Chat Application

JAVA · MAVEN
purpose

A console-based chat application covering the full flow from account registration through to sending and managing messages.

description

Users register with a first name, last name, username, password, and South African cell phone number, each checked against a set of validation rules. Once logged in, users can create and manage messages, including the message content, recipient, and status (sent, received, or read).

technologies

Java, Maven, JUnit for unit testing, Git & GitHub for version control
