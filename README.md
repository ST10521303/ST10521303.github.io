# Publishing this to GitHub Pages

1. Create a new repository on your account (`ST10521303`) — name it something like `portfolio` or `ST10521303.github.io` (the second option makes your URL just `https://ST10521303.github.io`, no repo name needed).
2. Upload all five files in this folder (`index.html`, `about.html`, `projects.html`, `reflection.html`, `contact.html`, `style.css`) to the root of that repository.
3. In the repository, go to **Settings → Pages**.
4. Under "Branch," select `main` and `/ (root)`, then save.
5. Wait a minute or two, then your site will be live at the URL GitHub shows on that same Pages settings page.
6. Open the link yourself in a private/incognito window to confirm it loads without needing to be signed in — that's what your lecturer will see.
